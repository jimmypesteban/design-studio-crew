# Brand notes

- Moon's secondary (blue) and tertiary (grey) button styles fail contrast with white text, so cta_variant only offers primary, highlight and accent.
- On a dark panel (mo-ocean, mo-forest) use mo-white text. On mo-grey-1 use mo-black.
- Calm artwork with open space works best. The text panel covers part of the image.
- Image prompts that name the Moon colours as hex values keep the artwork closer to the palette.
